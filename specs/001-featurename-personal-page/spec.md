### User story 1: viewing contacts.
A visitor opens the page and sees an email, a link to GitHub and LinkedIn. They can follow any link or copy the email. If they click on the email, the mail editor opens automatically.

**Why this priority**: The feature is a priority because presenting my contact information is the main function of the site.

---

### User Story 2 – navigating to the notes page

After viewing the contact information, the visitor can go to the notes list page.

**Why this priority**: Bcs need links beetwen pages
