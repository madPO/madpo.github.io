# 'Madpo personal page' Constitution

## Core Principles

### Principle 1: keep it as simple as possible
All pages must be as simple as possible — the main content element, a menu, and that’s it. No distracting elements. If it’s possible not to use some technology or dependency, then it shouldn’t be used. Each page should load as quickly as possible.

### Principle 2: chiaroscuro style in design
The primary color scheme is dark. Use the `chiaroscuro` style for illustrations and controls where possible.

### Principle 3: SEO-friendly
The content must be searchable. Therefore, all approaches to improving SEO should be applied. Content accessibility for people with impairments must also be supported. The color scheme should be high contrast, but not maximal (the APCA system should be used). Elements on the page must be accessible to screen readers.
